## 프로젝트

### [Barrier Free — 교내 도로 위험 후보 지도](https://github.com/SongRoute/barrier-free)

Raspberry Pi·IMU·GPS 데이터를 활용해 소형 바퀴 이동에 위험할 수 있는 도로 구간을 찾고, 지도에서 주행과 전후 변화를 비교하는 MVP입니다.

- **살펴볼 내용:** 센서 데이터 수집, 데이터 품질 점검, 구간별 집계, 분류 모델, 지도 시각화
- **기술:** Python, Raspberry Pi, IMU/GPS, Leaflet
- **현재 범위:** mock 기반 실행 흐름과 실제 센서 수집 절차를 제공합니다. 실제 휠체어 안전을 확정 판정하는 시스템은 아닙니다.
- [프로젝트 설명 및 실행 방법](https://github.com/SongRoute/barrier-free#readme)

### [Baseball Zerobase — MLB 투구 전략 연구 파이프라인](https://github.com/SongRoute/baseball-zerobase)

MLB 투구 전 상황을 구성하고, 시점 기반 데이터 누수 방지와 전이 모델·투구 후보 추천을 다루는 연구 프로젝트입니다.

- **살펴볼 내용:** 원천 데이터 수집, 투구 전 특징 생성, 시간 순서 검증, 전이 확률 모델, 추천 CLI
- **기술:** Python, Parquet, uv, pytest, Ruff, Pyright
- **현재 범위:** 추천 순위는 즉시 전이 위험의 대리 점수(`transition_proxy`)를 사용합니다. 이닝 기대실점에 기반한 추천이나 실전 효과가 검증된 서비스로 소개하지 않습니다.
- [한국어 설명](https://github.com/SongRoute/baseball-zerobase/blob/master/README.ko.md) · [실행 방법](https://github.com/SongRoute/baseball-zerobase#readme)
